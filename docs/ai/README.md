# AI와 함께 rl 쓰기

[`rl.md`](./rl.md)는 **AI 코딩 도구에게 rl을 가르치는 컨텍스트 문서**입니다.
AI가 `.rl` 파일을 올바르게 읽고 쓰는 데 필요한 전부 — 일곱 구문, 통과 계약,
흔한 실수, 빌드 설정 — 를 한 파일에 담았습니다. AI 도구 호환성을 위해
영어로 작성되어 있고, 자기 완결적이라 이 저장소 밖에서도 그대로 동작합니다.
사람이 읽는 문서가 아니므로 컨텍스트 비용을 줄이기 위해 최대한 압축된
표기(짧은 규칙 나열)를 씁니다. 사람을 위한 시작 안내는 [README](../../README.ko.md)에 있습니다.

## 사용법

rl을 쓰는 **여러분의 프로젝트**에 `rl.md`를 복사해 넣고, 사용하는 AI 도구가
읽도록 연결하면 됩니다.

```sh
mkdir -p docs
curl -o docs/rl-ai-guide.md \
  https://raw.githubusercontent.com/load28/rl/main/docs/ai/rl.md
```

| 도구 | 연결 방법 |
|------|-----------|
| Claude Code | 프로젝트 `CLAUDE.md`에 `@docs/rl-ai-guide.md` 한 줄을 추가하거나, 내용을 `CLAUDE.md`에 직접 붙여넣기 |
| Cursor | `.cursor/rules/rl.mdc`로 저장 (프론트매터에 `globs: ["**/*.rl"]`을 주면 `.rl` 파일 작업 시 자동 적용) |
| GitHub Copilot | `.github/copilot-instructions.md`에 내용 추가 |
| Codex · Jules 등 AGENTS.md 계열 | 프로젝트 `AGENTS.md`에 내용 추가 또는 링크 |
| 그 외 (챗 기반) | 대화 시작 시 파일 내용을 시스템 프롬프트/첫 메시지로 붙여넣기 |

`npm install rl-lang`을 쓰는 프로젝트라면 설치된 패키지 대신 위처럼 저장소의
최신 문서를 받아 두고, rl 버전을 올릴 때 함께 갱신하는 것을 권장합니다.

**같은 가이드가 컴파일러에도 임베드되어 있습니다** — 설치된 rlc에서
`npx rlc help`(주제 목록), `npx rlc help match`(주제별),
`npx rlc help all`(전체)로 꺼낼 수 있어, AI가 작업 중 네트워크 없이 문법을
찾아보거나 컨텍스트 파일 없이도 스스로 가이드를 조회할 수 있습니다.

## 이 문서가 다루는 것

- **통과 계약**: 유효한 TS는 그대로 유효한 `.rl`이고, 어긋난 rl 구문은
  에러가 아니라 조용히 통과된다는 것 — AI가 가장 자주 빠지는 함정.
- **각 구문의 규칙**: 필수 괄호·세미콜론, 이름 기준 바인딩, 리터럴
  패턴 없음, 소진성 검사에서 가드/중첩 암이 커버로 인정되지 않는 것 등.
- **`@rl/std` 치트시트**: `Option`/`Result`의 필드명(`value`/`error`)과
  콤비네이터, 파이프라인용 `*P` 변형.
- **빌드 파이프라인**: `rlc` 명령, `tsconfig` 설정, 번들러(unplugin-rl),
  `.rl-types` 사이드카.
- **에러 읽는 법과 마무리 체크리스트**.

## 유지 관리

이 문서는 컴파일러에 그대로 포함되는 AI용 언어 가이드입니다. **언어 표면이
바뀌면 이 문서도 함께 갱신해야 합니다.** 구현과 어긋나면 버그로 취급합니다.
