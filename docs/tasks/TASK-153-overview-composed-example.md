## 의사결정

### 결정 1: 성공 경로 변환 후 마지막에 match한다

- **상황**: 세 기능을 모두 보여주면서 첫 화면의 예제가 길어지지 않아야 한다.
- **검토한 대안**: Result enum을 직접 선언하면 조합보다 선언이 중심이 된다. result 블록은 세 기능 외에 새로운 문법까지 추가해 첫 예제의 정보량이 늘어난다.
- **선택과 근거**: `parse` 결과를 `Result.mapP`로 변환하고 마지막 파이프 단계에서 `match`한다. 8줄 안에서 Result, 파이프, 성공·오류 분기를 모두 보여준다.
