## 의사결정

### 결정 1: 영문과 한글 문서를 분리한다

- **상황**: 두 언어를 유지하면서도 처음 방문한 사용자가 짧게 읽을 수 있어야 한다.
- **검토한 대안**: 한 파일에 두 언어를 연속 배치하면 내용이 길어지고, 영문만 유지하면 한글 요구를 충족하지 못한다. 별도 파일은 각 문서가 짧고 언어 전환이 명확하다.
- **선택과 근거**: `README.md`를 영문 기본 문서로 두고 `README.ko.md`를 같은 구조의 한글 문서로 둔다. 각 문서 상단에서 서로 연결한다.

### 결정 2: 상세 레퍼런스 대신 컴파일러 내장 도움말을 안내한다

- **상황**: `docs/reference/`를 삭제한 뒤에도 사용자가 문법과 CLI 도움말을 찾을 경로가 필요하다.
- **검토한 대안**: 상세 내용을 README로 옮기면 다시 비대해진다. 별도 레퍼런스를 유지하면 삭제 요청과 어긋난다. `rlc help`는 이미 컴파일러와 함께 배포되고 테스트된다.
- **선택과 근거**: README에는 기능의 감각만 보여주고 상세 사용법은 `rlc help <topic>`과 `rlc --help`로 연결한다.
