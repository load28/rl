## 목적

`docs/ai/rl.md`(TASK-052)는 AI 도구가 컨텍스트로 읽는 문서라 사람이 읽을
일이 없다. 사용자 요청에 따라 규칙 손실 없이 산문을 제거하고 표기를 압축해
컨텍스트 비용(파일 사이즈)을 최소화한다.

## 범위

- 포함: `docs/ai/rl.md` 압축 재작성, `docs/ai/README.md`의 문서 성격 설명
  갱신.
- 제외: 규칙·내용의 추가/삭제(압축 과정에서 규칙이 빠지면 버그), 레퍼런스
  변경.

## 의사결정

### 결정 1: 압축 방식 — 산문 제거 + 규칙 나열, 예제는 최소 유지

- **상황**: "최대한 작게"와 "AI가 정확히 따라 쓸 수 있게"의 균형점이
  필요했다.
- **검토한 대안**: ① 전면 산문 유지(원본 — 14.9KB), ② 예제까지 전부 삭제한
  순수 규칙 목록(최소 크기지만 구문 형태를 예제 없이 텍스트로만 설명하면
  모델의 재현 정확도가 떨어짐 — 예제 코드는 문자 수 대비 전달량이 가장 높은
  표기), ③ 산문·중복(방출 코드 블록, 장황한 체크리스트)을 제거하고 구문당
  최소 예제 하나만 남기는 압축 표기.
- **선택과 근거**: ③. 규칙 전체를 보존하면서 14,941 → 9,835바이트(-34%)로
  줄었다 (`wc -c`로 확인). 남은 내용은 거의 전부 규칙이라 추가 압축은 규칙
  손실을 수반한다.
